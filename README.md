# lfcaps

version 0.2-dev.jbcj

Linux file capabilities (cap_chroot,cap_setuid,..) C user layer and tools



```
lfcaps 0.2-dev.jb75

Usage: lfcaps [-vhulLasdciptN] [-n capnames]  [file] [file2] ..

 -h                help
 -u                show usage
 -v                verbose
 -l                list caps (default)
 -L                list caps, if present
 -a                add caps
 -s                set caps
 -d                delete caps
 -c                clear all caps
 -i                modify inheritable capset
 -p                modify permitted capset (default)
 -t                test for capabilities
 -n capnames       capset, caps separated by ','
 -N                list cap names
```
